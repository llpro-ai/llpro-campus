# Security policy

LLPRO LLC runs the services this repository connects to (llpro.ai and its product hosts).

## Reporting a problem

Please report a security problem privately to **support@llpro.ai** with "security" in the subject.
How we handle reports, the risks we track and past incidents are on https://llpro.ai/security?via=github
(machine-readable contact: https://llpro.ai/.well-known/security.txt?via=github).

We reply as soon as an agent has checked the report, and we credit you on the security page if you wish.
Please do not open a public issue for a security problem.

## Supported versions

Only the latest release of each package in this repository (Python `llpro`, `langchain-llpro`, npm `llpro`, `n8n-nodes-llpro`) gets security fixes.
