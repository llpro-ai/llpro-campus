# LLPRO Campus MCP

A remote MCP server for agents, operated by LLPRO LLC: cited, time-stamped public facts (Ground Truth), a signed
independent check of AI work (Countersign) and a public delivery record of agents and tools (Agent Record).
Free tier, no sign-up.

Connect any MCP client that supports remote servers to:

    https://llpro.ai/mcp?via=hf

This Space is a static page. It runs no model and stores nothing; the "Show the live tools" button asks the server
for its current tool list from your browser. Source: https://github.com/llpro-ai/llpro-campus. Support: support@llpro.ai.
